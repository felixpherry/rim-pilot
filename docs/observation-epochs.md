# Observation epochs and sampling boundaries

**Private authorization prerequisites for registered observations.** `ObservationEpochs` tracks irreversible safety, readiness and source revisions. `ReadDispatcher` supplies trusted game-thread evidence under the existing transition read fence and update deadline. Baseline producers require fresh field/release admission as well. Health exposes optional authorized root/game scope only while safe/ready; capabilities describe registered routes without map, manifest, window or developer-state data. Source audit and host tests do not prove installed Mono detours or full-profile safety.

## Ownership and release

- A lease binds exact process-local epoch owner, public scope and all three positive revisions. It is never serialized. Safety changes/uncertainty, readiness loss/recovery, source/scope changes and frame/size/scale discontinuities revoke earlier leases. Returning to the same state cannot restore them. Counters never wrap: exhaustion permanently closes admission.
- Missing, failed, incomplete or budget-exhausted samples cannot preserve admission. Invalid geometry includes absent evidence, negative frame, nonpositive dimensions, nonfinite/nonpositive scale. Frame regression or a gap greater than one invalidates; repeated frame values are allowed for multiple GUI passes but certify no rendering. Consecutive frame values alone are not source-eligibility witnesses.
- At most eight registered `IObservationInvalidationSink` owners receive immediate invalidation after revocation, including active builds already removed from the pending queue, retained snapshots, public event stores and captures. Dispatcher/snapshot, event and capture owners now implement these interfaces. Callbacks must only cancel/clear bounded managed state; loading workers must never destroy Unity resources. Game-thread cleanup remains producer-owned. A throwing sink does not prevent notification of the other owners and permanently closes admission.
- `Acquire` requires complete safe/ready evidence. `Release` requires a fresh trusted game-thread sample, current scope/geometry and remaining shared budget. It rechecks every revision before a bounded primitive-only ownership transfer, under the same epoch lock. A worker cannot revoke between final admission and transfer. The producer must also retain the transition read fence through sampling and transfer, recheck deadline/disconnect and audit current eligibility; an epoch is not field authorization or a collection-version witness. No client-supplied closure is queued or executed.
- Known unsafe developer evidence takes precedence over loading, stale scope and old leases. Incomplete developer audit refuses ordinary ready reads. Safe authorization alone never suffices: registered producers must independently prove field and whole-result eligibility. Already admitted/transmitted historical primitives cannot be recalled; the release boundary is the authorization point.

## Installed-source boundary audit

Inspected installed RimWorld 1.6.4871 rev600 sources and Unity bindings; private sources/hashes remain outside the repository. Exact metadata lookup uses declared method name and signature, not runtime enumeration or client-selected reflection.

| Boundary | Installed behavior and product handling |
| --- | --- |
| `Root.Update` | Runs long events and UI update, catches/logs internal exceptions. Retained only as initial game-thread bootstrap callback, not dispatch/render completion. |
| `Root_Entry.Update()` / `Root_Play.Update()` | Call base first, then entry/world/game update or `Current.Game.UpdatePlay`. Prefix revokes prior authorization; finalizer balances the bracket and samples/dispatches only after the derived call. This fixes the base-postfix-before-simulation ordering. |
| `Root.OnGUI()` | Applies UI scale, long-event GUI, ordinary UI/windows, fader and camera GUI; Unity invokes multiple layout/repaint/input passes. Prefix revokes prior leases; finalizer samples only, without dispatching extra work per GUI pass. Returned GUI callback does not prove native completion or absence of stale pixels. |
| `Prefs.set_DevMode(bool)` | Installed setter changes backing state, may remove the palette and calls Apply ONLY when the value differs (`if (data.devMode != value)`); Options > General writes the current value every GUI frame. Prefix/finalizer invalidate for every changed write, exception, skipped original or value altered after the original (foreign patch); a write of the value already held is not a bracket (otherwise the open Options General tab permanently refuses screenshots, found by private diagnostic P4-11-R2). Bridge never invokes setter. |
| `Prefs.set_UIScale(float)` | Stores preference scale. Bracket invalidates even change-and-restore between sampled endpoints; bridge reads scale only, never applies/changes it. |
| `WindowStack.Add(Window)` | Removes same-type windows and invokes PreOpen/PostOpen around insertion. Bracket covers callback failures and add/remove developer intervals. |
| `WindowStack.TryRemove(Window,bool)` | Performs membership, close-request, sound and PreClose/PostClose around removal. Bracket covers all higher-level Type/assignable removal paths that delegate here; bridge does not invoke removal. |
| Existing transition hooks | Current game/program state, scene/root, game/world/map lifetime and long-event brackets revoke epochs immediately alongside pending requests, including worker transitions and same-reference returns. Bounded safe generation sampling still detects raw map-list version changes. |

Finalizers preserve the original result/exception and balance entered brackets once; retries conservatively invalidate without double-decrement. A missing prefix cannot provide safe interval evidence. `Root` catches many exceptions internally, so absence of an escaping exception is not successful-render evidence. Exact inherited `destroyed` field injection and new finalizer detours still require isolated Mono validation.

Developer sampling runs before ordinary readiness admission so known DevMode can refuse even during loading; `DeveloperSafetySampler` checks DevMode before attempting window/static inspection. Loading or invalid roots never authorize map reads. Sampling/readiness/generation work shares one dispatch deadline; GUI sampling has its own bounded callback deadline and never grants another request quota. Elapsed checks cannot preempt JIT/native calls or claim a hard wall-clock limit.

## Deliberate conservative boundary

Every unobserved update/GUI interval revokes old leases even if endpoint samples are both safe. This prevents an unsafe-on/off interval from being mistaken for uninterrupted authorization; it deliberately does **not** manufacture proof that the interval was safe. Static debug flags have direct writes, not universal setter hooks. Arbitrary mod callbacks, background writes, raw window mutations or patches bypassing these hooks remain outside this finite audit. Later exact provider/patch admission and interval-wide source/render witnesses remain required.

Cross-frame producers must obtain appropriate new authorization and prove whole-vector eligibility, not keep or relabel revoked leases. No `CompletedRenderStamp` or `RenderEvidence` is minted by this tracker. Native provenance, capture/readback/PNG cleanup, public event storage/hooks, snapshot storage (shared producer scheduling now lives in [read dispatch](read-dispatch.md#shared-producer-scheduling)) and real menu/pause/live UI comparison remain separate tasks. There is no completed-render proof from Update, OnGUI, frame integers, marker yields or native API return alone.

Host tests cover irreversible on/off/recovery, nested/worker boundaries, all four future owner classes, active work outside the queue, failures/deadlines, discontinuities, scope/owner mismatch, thread refusal, atomic release and developer-refusal precedence. Existing strict method parsing and minimal capabilities remain unchanged: no actions, raw input, developer, reflection or code execution route.
